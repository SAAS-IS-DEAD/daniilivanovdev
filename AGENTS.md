# Правила разработки

## Обязательные тесты (указание владельца от 2026-11-05)

- Каждая новая или изменяемая фича MUST иметь unit-тесты наблюдаемого поведения.
  Для React это компонентные тесты Testing Library; для правил — чистые unit-тесты.
- Для backend-фич дополнительно MUST быть интеграционные тесты через Nest/HTTP/GraphQL
  и настоящую отдельную PostgreSQL. Моки repository не заменяют такие проверки.
- Сначала добавить проверку и убедиться, что она падает по ожидаемой причине;
  затем реализовать/исправить поведение и получить зелёный результат.
- Тестировать успешный сценарий, ошибки, границы и относящиеся к фиче гарантии данных.
  Багфикс MUST иметь регрессионный тест. Не писать проверки, повторяющие реализацию.
- Фича без этих тестов не считается завершённой. Не отключать/пропускать тесты,
  не снижать coverage thresholds и не исключать продуктовый код ради зелёного CI.
- `npm run verify` — обязательный финальный gate (build, Biome, types, unit,
  backend integration, contract и coverage). Нужен работающий Docker: Testcontainers
  сам создаёт PostgreSQL со случайным портом и удаляет её после прогона.
  Не задавать TEST_DATABASE_URL вручную и не возвращать постоянную fallback-базу.
- Для изменений браузерного взаимодействия дополнительно запускать относящиеся E2E.
- Никогда не запускать очистку/фикстуры на рабочей БД. Не ослаблять assertTestDatabase.
- Точки входа и декларативный wiring проверять сборкой, интеграцией и smoke/E2E;
  не добавлять фиктивные unit-тесты ради процента.
- Coverage — нижняя граница, не доказательство всех сценариев. Новый сценарий проверять
  независимо от уже достигнутого процента; ограничения честно записывать в validation.md.

## Текущий объём

Синхронизация hh.ru приостановлена владельцем. Не продолжать её без нового указания.
Авторизация сайта, админка и CRUD отменены. Активные требования — в
`specs/001-digital-business-card/`, архивы не являются текущими задачами.

## Инструменты

TypeScript/NestJS + Prisma/GraphQL, React/Vite и генерируемый graphql-request SDK.
Форматирование и lint: Biome (`npm run format`, `npm run check`).
Node из `.node-version`; системный Node на машине может быть старее.
